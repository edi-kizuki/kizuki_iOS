## Hub

The project hub exists in `hub/`. Start it with `bun hub/serve.ts` (prints the URL, default `http://127.0.0.1:4747/`). Card data lives in `hub/cards.json`; decision pages in `hub/decide/`; the walkthrough is generated by `bun hub/build.ts`. Repo `docs/` is served read-only under `/docs/`, so link to docs, never copy them. Deploy to Vercel is pending user approval.
