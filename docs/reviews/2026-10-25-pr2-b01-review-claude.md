## Checked and sound

- **Production refusal and staging pin.** `.production` always throws, and `.local` throws in non-Debug (`AppConfiguration.swift:38-51`). `.staging` requires the exact `ankgfqkgflcalmlreetu.supabase.co` with https and no port. Lookalike and suffix hosts are rejected (Swift test plus Python test). `test-release-runtime-guard.sh` compiles the file without `DEBUG` and covers 4 cases. One open item: the Python validator still allows production (R-08).
- **No fixture leak into live.** `Dependencies.live` uses only `SupabaseBackend` plus `UnavailableRepositories`. `MainTabs` (moved out of `#if DEBUG`) has no fixture references. `PrototypeRoot`, `GalleryScreen` and `UITestBackend` stay Debug-only. `-live -screen home` ignores the gallery router.
- **Honest failure.** All 19 pending repository methods throw `LiveRepositoryError.notYetAvailable`, and a test calls each one and rejects any success. `LiveTabs` shows "Live features are not available yet." plus Sign out. No invented data.
- **Session races.** Events are processed serially. `activate` sets `.restoring`, awaits old-scope cleanup, then re-checks `generation` and cancellation before creating the new scope. `signOut` and `refreshProfile` are gated on `.signedIn`, so they cannot interleave with a transition. Late sign-out responses are fenced by user ID **and** scope generation. Late profile responses are fenced by `generation`. Observer cancellation cancels the scope.
- **SDK usage (2.55.4).** One `SupabaseClient` per process. PKCE, Keychain storage key per environment, `emitLocalSessionAsInitialSession: true`. `authStateChanges` emits the initial session per subscriber. Sign-out `.local` clears storage before network revocation (`AuthClient.swift:1100-1103`), matching the backend's tolerant catch. Eligibility comes from `legal_acceptances.age_confirmed`, not auth metadata, and the embed decodes as an array (1–N per v2 §4.2).
- **Concurrency.** Swift 6 language mode with `SWIFT_STRICT_CONCURRENCY: complete`. `AppSession` and `SessionScope` are `@MainActor`. `Dependencies` holds `Sendable` existentials. The `SupabaseBackend` stream task is cancelled via `onTermination`.
