# B18 Push

Map: [[2026-10-25-wayfinder-map]]. Concept: [[2026-10-25-architecture-concept-v2]], [[2026-10-25-architecture-concept-v2.1]].

## Goal

APNs pushes for request, acceptance and message, delivered per device with fenced retries.

## Concept references

v2 §2.9; ticket 035 (VF06).

## Exit criteria (tests that prove it)

- Token register/unregister/reassign; per-device delivery rows; fenced leases; Vault fast path + cron drain; `send-push` with server secret; Push capability.
- pgTAP outbox rows per event; Deno tests: user JWT rejected, forged body ignored, mixed 200/410/429 across two devices, stale lease completion.
- Device push verification after D39 (ticket 006) is a B20/B21 checklist item.
- Every slice: tests start from an empty local DB with migrations up to this slice only (`scripts/test-prefix.sh <slice>`); fixture UI tests stay green; new UGC surfaces have Report; user-linked tables extend `private.freeze_account` and the FK matrix (v2.1 §3.3).

## Risk class

ENV + PRIVACY.

## Cross-model review

Required (playbook rule 1: secrets and cross-user delivery; changes 3+ files). Reviewer is the other model family (D45); max two review rounds.
