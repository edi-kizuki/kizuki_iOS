## Goal

Live chat with message envelopes in Realtime and bodies fetched separately, so moderation never leaks text.

## Concept references

v2 §2.6; v2.1 §2 (whole), §3.4 (B08).

## Exit criteria (tests that prove it)

- `messages` envelope (no body column), `message_bodies` (not in Realtime), `send_message`, `ChatTransport`, Inbox, thread, unread, mute.
- v2.1 §2.4 M1–M10 pass; VF10 gap-recovery tests pass.
- Live Swift run: real app on a simulator with `-live` against the local Supabase stack, second user scripted; `.xcresult`, screenshots and a run note in `docs/lanes/` (v2.1 §3.5). Reviewer re-runs it. Flow: two users exchange messages, one message hidden, client purges text, reconnect recovers missed messages.
- Every slice: tests start from an empty local DB with migrations up to this slice only (`scripts/test-prefix.sh <slice>`); fixture UI tests stay green; new UGC surfaces have Report; user-linked tables extend `private.freeze_account` and the FK matrix (v2.1 §3.3).
